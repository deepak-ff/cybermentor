# Contributing

Thanks for your interest in contributing to this project. Suggested contributions:

- Open a concise issue describing the bug or enhancement.
- Fork the repo and create feature branches named `feat/xxx` or `fix/yyy`.
- Add tests for new functionality and run `pytest` before submitting a PR.
- Follow existing code style; run `black` or your formatter of choice.

Please include tests and update `README.md` for any user-facing changes.
